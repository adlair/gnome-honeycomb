# Changelog

## 1.0.0 — 2026-08-10

- Initial public release for GNOME Shell 50.
- Centered spherical application navigation using a deterministic Fibonacci distribution.
- Mouse-driven yaw/pitch rotation with fixed visual center.
- Magnetic magnification and local bubble repulsion.
- Depth-aware scale, fade and stacking.
- Complete application discovery with GNOME app folders flattened into individual apps.
- Stock AppGrid pagination controls hidden while Honeycomb is active and restored on exit.
- Lifecycle cleanup for signals, actors and GLib sources.
